통합 CBT 모의고사 사용방법

실제 시험과 유사한 환경에서 연습하기 전 아래 사용방법을 먼저 확인해 주세요.

1

비밀번호 입력 후 시험장 입장하기

먼저 화면의 비밀번호 입력 칸에 안내받은 비밀번호를 입력한 뒤 ‘시험장 입장하기’를 클릭합니다.

2

엔트리 화면과 문제창 준비하기

각 급수에 맞는 엔트리 배포파일을 열고 문제창과 엔트리창을 나란히 배치합니다.
(2급은 인공지능 데이터를 사용해야 하므로 반드시 로그인 해주어야 합니다.)

3

원하는 급수 선택 후 시험 시작하기

원하는 급수를 선택한 후 ‘시험 시작하기’를 눌러 시험을 시작합니다.

4

2급 3번 데이터 문제 배포파일 다시 열기

2급은 엔트리 데이터 문제가 2문제인데, 배포파일 하나에는 데이터 모델이 하나밖에 들어가지 않습니다. 따라서 3번 문제 파일을 다시 열어야 합니다.

파일을 다시 여는 동안 시험 시간이 흐르지 않도록 ‘일시정지’ 버튼을 누른 뒤 3번 문제 파일을 열고, 준비가 끝나면 다시 시간을 진행시켜 문제를 풀어 주세요.

5

파이썬 문제 답안 작성하기

파이썬 문제는 코드창에 있는 빈칸을 클릭하여 답안을 작성하세요. 참고로 이 CBT 화면에서는 Python 코드를 직접 실행해 볼 수 없습니다.

6

문제마다 저장하기

실제 시험과 유사한 환경으로 문제마다 ‘저장’ 버튼이 있습니다. 답안을 작성한 뒤 저장을 누르고 다음 문제로 넘어가는 연습을 해 보세요.

7

문제 번호로 이동하기

화면 상단의 문제 번호를 누르면 원하는 문제로 바로 이동할 수 있습니다.

안내를 모두 확인했나요? 새 탭에서 통합 CBT 모의고사를 열어 연습을 시작해 보세요.
