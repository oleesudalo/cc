통합 CBT 모의고사 사용방법

실제 시험과 유사한 환경에서 연습하기 전 아래 사용방법을 먼저 확인해 주세요.

1

비밀번호 입력 후 시험장 입장하기

먼저 화면의 비밀번호 입력 칸에 안내받은 비밀번호를 입력한 뒤 ‘시험장 입장하기’를 클릭합니다.

2

엔트리 화면과 문제창 준비하기

각 급수에 맞는 배포파일을 열고 아래와 같이 문제창과 엔트리창을 나란히 띄워 준비합니다.

2급은 배포파일이 두개이므로 두개 다 열어서 준비하고 첫번째 파일을 위에 띄워 준비합니다..

* 2급 엔트리의 경우 인공지능 데이터 사용을 위해 엔트리 로그인이 반드시 필요합니다

3

원하는 급수 선택 후 시험 시작하기

원하는 급수를 선택한 후 ‘시험 시작하기’를 눌러 시험을 시작합니다.

4

2급 엔트리 배포파일이 두개인 이유

2급은 엔트리 데이터 문제가 2문제인데, 배포파일 하나에는 데이터 모델이 하나밖에 들어가지 않습니다. 따라서 2번까지 풀고 난 후 3번 배포파일 창을 띄워줘야 합니다.

창을 띄우는 동안 시험 시간이 흐르지 않도록 ‘일시정지’ 버튼을 누른 뒤 3번 문제 파일을 열고, 준비가 끝나면 다시 시간을 진행시켜 문제를 풀어 주세요.

5

파이썬 문제 답안 작성하기

파이썬 문제는 문제칸에 있는 빈칸을 클릭하여 답안을 작성하세요. 참고로 이 CBT 화면에서는 Python 코드를 직접 실행해 볼 수 없습니다.

6

문제마다 저장하기

실제 시험과 유사한 환경으로 문제마다 ‘저장’ 버튼이 있습니다. 답안을 작성한 뒤 저장을 누르고 다음 문제로 넘어가는 연습을 해 보세요.

7

문제 번호로 이동하기

화면 상단의 문제 번호를 누르면 원하는 문제로 바로 이동할 수 있습니다.

안내를 모두 확인했나요? 새 탭에서 통합 CBT 모의고사를 열어 연습을 시작해 보세요.
